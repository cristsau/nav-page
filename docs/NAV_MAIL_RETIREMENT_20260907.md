# DOMO NAV 个人邮箱下线与磁盘收口

决策日期：2026-09-07。状态：LOCAL_CANDIDATE / NOT_PUSHED / NOT_DEPLOYED。

## 产品边界

项目所有者要求不再开发个人邮箱，集中维护已有功能。退出个人邮箱的收件、邮件搜索、写信/回复/转发、
草稿、文件夹、附件处理、邮件 AI、分类、摘要及其通知。不是继续保留一个缩减的“邮件雷达”。
保留导航/剪藏、统一搜索、时光/日记/备忘、媒体库、AI 资料检索与受控操作、Google 身份登录、
Web Push、注册验证/审批/运维 SMTP 通知。未擅自移除协作、离线或微信代码，未新增分享评论。

## 已实现

- 主导航与命令面板不再出现邮件。`/mail` 兼容旧链接但展示下线说明；旧客户端邮件 API 返回 410。
- 移除邮件/SSE 路由和邮箱 OAuth 管理接线；系统集成改为身份、系统通知、云备份三个独立区域。
- IMAP/分类/附件/发送副本/摘要/邮件缓存定时任务不再启动；旧环境变量与持久化开关不能重新激活。
- `nav-mail-worker` 从 Compose 移除，旧启动脚本只输出退役说明后退出，备份/灾难恢复默认列表同步调整。
- AI 工具目录不再开放四个邮件工具；旧确认单在解密或执行前拒绝；对话不再检索邮件。
- SMTP 发送器启用系统消息类型白名单。旧个人邮件和摘要 outbox 不投递，邮件站内通知/推送也不再续发。
- `imapflow`、`mailparser`、`pdfjs-dist`、`saxes`、`yauzl` 转为开发依赖，仅供历史数据/恢复回归；生产镜像不安装。
  增加真实 API 生产依赖导入启动检查和静态传递依赖检查，避免只是“删依赖后无法启动”。
- 现有已发布迁移、邮箱表、历史加密内容和密钥不删除、不清空；兼容回滚和受控数据处理。
