## 本批能力

### 提前提醒

- 备忘录可选择准时、提前 10/30/60 分钟、1 天或 7 天提醒。
- 服务端按数据库 advisory lock 串行生成提醒，单轮和运行间隔都有上限。
- NAV 页面打开时每分钟刷新提醒；系统通知必须由用户在浏览器中主动授权。
- 加密备忘录的通知只显示通用标题，不显示正文或真实标题。
- 迁移 024 候选已增加标准 Web Push：网页关闭后可由 Push 服务商送达；必须由用户逐设备授权，
  VAPID 私钥只从服务端只读 Secret 文件加载。

生产候选环境变量（默认全部关闭）：

```dotenv
NAV_NOTE_REMINDER_SCHEDULER_ENABLED=false
NAV_NOTE_REMINDER_SCHEDULER_INTERVAL_SECONDS=60
NAV_NOTE_REMINDER_SCHEDULER_BATCH_SIZE=500
```

### 定时失效链接检查

- 后台任务复用手动检查的 DNS 固定、私网地址拒绝、重定向复核、短超时和不读取正文策略。
- 单轮批次最多 100、并发最多 6，并通过 advisory lock 防止多副本重复运行。
- 默认只检查 7 天未检查的书签；连续两次失败才判定为失效。
- 首页集中展示失效、待复核和无法安全检查的链接，可单条或批量复查。
- 管理员可在“账号安全与审计”的后台维护状态中查看最近运行结果。

生产候选环境变量（默认全部关闭）：

```dotenv
NAV_BOOKMARK_HEALTH_SCHEDULER_ENABLED=false
NAV_BOOKMARK_HEALTH_SCHEDULER_INTERVAL_SECONDS=3600
NAV_BOOKMARK_HEALTH_SCHEDULER_BATCH_SIZE=20
NAV_BOOKMARK_HEALTH_SCHEDULER_STALE_HOURS=168
NAV_BOOKMARK_HEALTH_SCHEDULER_CONCURRENCY=4
```

### 导入与导出

- 设置的数据页可读取 Chrome/Edge 导出的 Netscape Bookmark HTML。
- 原文件只在浏览器中解析；先预览，再选择目标分组、是否保留目录，按“分组 + 规范化 URL”去重。
- 只接受无账号信息的 HTTP/HTTPS 链接，单文件不超过 5 MB、单次最多 1000 个链接。
- 笔记可导入普通 Markdown 或 DOMO NAV 多条记录格式，单次最多 200 条。
- 服务端导入各使用一次受限请求和数据库事务，不会逐项撞上每分钟 120 次写入保护；任一写入失败会整体回滚，不留下“导入一半”的状态。本地浏览器模式继续使用本机事务能力。
- Markdown 导出保留支持的标签、日期、截止时间和完成状态；加密笔记及图片附件不会导出。

浏览器扩展商店发布仍需要 Chrome Web Store / Edge Add-ons 开发者账号、商店审核和真机确认；源码内已有下载包、侧载说明与快速添加页，本批不代替外部商店发布。

### 命令面板

- `Ctrl/Cmd + K` 可直接切换所有内置主题。
- 打开面板时读取服务端已发现的最多 6 个 AI 模型，可选择自动跟随最新模型或固定模型。
- 动态模型读取失败时，不显示模型命令，不用过期或猜测的模型名覆盖当前设置。

### PWA

- 生产 HTTPS 环境注册 Service Worker；预缓存清晰标识、图标和离线说明页。
- 哈希静态资源采用 cache-first；页面导航优先网络，离线时只显示说明页。
- 不缓存 API、账号数据、笔记、图片、公开分享或快速添加页面。
- 新 Service Worker 等待用户在设置页确认后才接管并刷新，避免编辑过程中自动刷新。

### 自动保存与版本历史

- 已存在且未加密的笔记在停止输入 1.2 秒后自动保存，并显示等待、保存中、成功或失败状态。
- 请求携带 revision；并发修改返回 409，不会静默覆盖其他设备的新内容。
- 页面离开和关闭编辑器前有未保存保护；自动保存进行时暂时禁止手动保存或关闭，避免双请求竞争。
- 服务端在每次更新或恢复前保存旧版本，每条笔记最多保留 50 个版本。
- 版本列表支持预览与恢复；加密版本列表不返回正文或密码散列。
- 图片附件仍不进入版本快照，恢复只恢复块正文和元数据；图片原图沿用当前引用生命周期。
- 旧本地模式支持自动保存，但持久化版本历史仅在 PostgreSQL 账号模式提供。

## 发布前门槛

1. CI 在 PostgreSQL 16 上执行迁移并运行 `verifyMigrations.js`。
2. 发布前完成数据库备份，并在隔离数据库做一次 022 迁移和版本恢复演练。
3. 首次发布保持两个后台任务关闭，先验收手动提醒和手动链接检查。
4. 分别小批量启用提前提醒、链接检查，观察维护状态和日志后再决定是否扩大批次。
5. Chrome、Edge、iPhone Safari 各做一次通知权限、PWA 更新和长表单真机验收。
