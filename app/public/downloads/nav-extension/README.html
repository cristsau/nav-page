DOMO NAV 浏览器扩展安装说明

  1. 先下载 nav-extension.zip，并解压到本地文件夹。
  2. 打开 Chrome 或 Edge，进入“扩展程序”页面。
  3. 开启右上角的“开发者模式”。
  4. 点击“加载已解压的扩展程序”，选择刚刚解压出来的文件夹。
  5. 打开扩展设置，把站点地址改成你的 DOMO NAV 地址，例如 https://nav.skrskr.net。
  6. 确保你已经在这个浏览器里登录 DOMO NAV，之后就可以用扩展按钮和右键菜单快速添加当前页。

如果你是 iPhone 用户，请回到 DOMO NAV 设置页，查看“iPhone 快速添加当前页”的快捷指令方案。
